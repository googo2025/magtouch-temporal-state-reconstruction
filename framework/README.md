# 共同磁场监督框架与来源

两条路线共用研究主线：物理结构组织可解释状态，实测磁场学习未知关系，状态产生的物理磁响应检验解释。共同概念不意味着它们共用一份权重、完全相同的几何校准、网络输入、损失或评分掩码。

[原始协议](protocols.json)保留显式459条记录的346拟合＋16内部监测＋97开发，以及共享482条记录的381拟合＋101开发。共有器件与记录来源、各自已冻结的布局/磁化和历史磁层身份分别说明。磁片运动是物理场读出的状态来源；普通节点与磁片耦合方式由各路线定义。

共同装置引用：[硬件与采集仓库](https://github.com/googo2025/MagTouch-RA-3d-trajectory-recon)。旧定位指标、噪声与速率不替代当前形变结果。统一方法及互补实验见[中文联合论文](../papers/joint/Magnetic_Supervision_main_zh.pdf)和[英文联合论文](../papers/joint/Magnetic_Supervision_main_en.pdf)。

各路线的代码、结果与引用保持分立，参见[总引用说明](../CITATION.md)。共享数值库依赖声明见[依赖文件](requirements-model.txt)；这一共同依赖列表不构成全训练复现或新增模型资格。
